개발 전달용 프로토타입입니다. 아래 규칙 그대로 구현되어 있습니다.

1. 화면 구조 (2뎁스 푸시)

  • 1뎁스 = 직군 목록, 2뎁스 = 해당 직군의 직무 목록
  • 전환은 좌우 푸시. 나가는 화면은 translateX(-26%) + opacity .4, 들어오는 화면은 translateX(100%) → 0 + 좌측 그림자
  • duration 380ms / easing cubic-bezier(.22,.9,.24,1)
  • 뒤로가기 아이콘은 2뎁스에서만 노출, 폭 0 → 20px로 확장

2. 선택 규칙

  • 1뎁스 "전체"는 단일 선택. 누르면 기존 선택이 모두 해제되고 전체만 체크됨
  • 2뎁스 "OO 전체"를 켜면 해당 직군의 개별 직무 체크가 모두 해제됨(그룹 단위 1개로 취급)
  • 개별 직무를 켜면 "OO 전체"는 자동 해제됨
  • 선택 0개가 되면 1뎁스 "전체"가 자동으로 체크됨
  • 선택한 직무 카운트 = 직군별(전체 선택 시 1) + 개별 직무 수의 합

3. 선택한 직무 영역

  • 2뎁스에서만 노출. 1뎁스에서는 접힘(grid-template-rows 0fr → 1fr, 320ms)
  • 칩 구조: [직군 칩(다크)] > [직무 칩(화이트)] ... 직군 단위로 묶임
  • 직군 전체 선택 시에는 다크 칩 하나만 노출되고 화살표/직무 칩 없음
  • 정렬: 가장 최근에 선택한 직무가 맨 앞. 해당 직군 그룹도 맨 앞으로 이동
  • 칩 영역 높이 82px 고정, 초과 시 세로 스크롤

4. 칩 모션

  • 추가: translateY(4px)+scale(.86)+opacity 0 → 1, 280ms, cubic-bezier(.34,1.25,.64,1)
  • 삭제: 누른 칩만 scale(.84)+opacity 0으로 180ms 축소 후 제거
  • 재배치: FLIP 방식으로 남은 칩이 340ms 동안 새 위치로 이동(점프 없음)
  • 이동하는 칩은 순서대로 14ms씩(최대 70ms) 지연시켜 물결처럼 자리 잡음
  • 직군 칩(다크) X = 해당 직군의 선택 전체 삭제

5. 체크박스·배지

  • 체크는 팝업이 아니라 선을 그려 넣는 방식(stroke-dashoffset 18 → 0, 340ms, 60ms 지연)
  • 박스는 동시에 scale 1 → .86 → 1로 눌리는 느낌만 340ms
  • 체크 글리프 비율은 디자인 스펙 그대로 20px 박스 안에서 12 × 8.67
  • 1뎁스 직군 행의 초록 배지 = 그 직군에서 선택한 개수(전체 선택 시 1). 숫자가 바뀌면 1.16배로 한 번 튕김

6. 기타

  • 초기화: 현재 화면 유지, 선택만 전부 해제
  • 공고 보기: 시트 닫고 상단 필터 칩에 "첫 직무명 외 N"으로 반영. 선택이 있으면 필터바에 초기화 버튼 노출
  • 필터바 칩을 다시 누르면 해당 시트가 다시 열림. 최신순 칩은 정렬 시트(추천순/최신순/마감임박순/조회순), 직무 칩은 직군·직무 시트
  • 정렬은 단일 선택. 고르면 체크 표시 후 220ms 뒤 시트가 닫히고 칩 라벨이 바뀜
  • 시트 등장: translateY(100%) → 0, 420ms
  • prefers-reduced-motion 설정 시 모든 모션 비활성화
